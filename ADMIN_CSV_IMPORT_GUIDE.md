## ⚠️ CRITICAL VALIDATION RULES

### 1. Taxonomy Must Match `exam_topics.csv` EXACTLY

The combination of `unit_code` + `macro_topic` + `micro_topic` **MUST** exist in `exam_topics.csv`.

**✅ Valid Example:**
```csv
unit_code,macro_topic,micro_topic
Unit 1: General Science,Physics,Mechanics & Properties of Matter
```

**❌ Invalid Example (will be rejected):**
```csv
unit_code,macro_topic,micro_topic
Unit 1: General Science,Physics,Thermodynamics
```
_(Not in approved catalog)_

### 2. PYQ vs VINA Rules

| Rule | PYQ (Previous Year) | VINA (Practice) |
|------|---------------------|-----------------|
| **Year Required** | ✅ YES (2000-2026) | ❌ Optional |
| **Auto-files to Paper** | ✅ YES (by exam_tag + year) | ❌ NO (needs manual paper assignment) |
| **Duplicate Detection** | ✅ Checked against existing PYQ | ✅ Cannot match PYQ content_hash |
| **Typical Year** | 2019, 2020, 2021, etc. | 2026 (future year) |

### 3. Exam Tag Rules

| Exam Tag | Part A GS | Part B Aptitude | Part C Language | Total |
|----------|-----------|-----------------|-----------------|-------|
| `TNPSC_GROUP_1` | 175Q | 25Q | — | 200Q |
| `TNPSC_GROUP_2` | 75Q | 25Q | 100Q (Tamil/English) | 200Q |
| `TNPSC_GROUP_4` | 75Q | 25Q | 100Q (Tamil) | 200Q |

## 🔄 CSV Upload Workflow

### Step 1: Prepare Your CSV
1. Open `question_import_template.csv` in Excel/Google Sheets
2. Reference `exam_topics.csv` to find approved taxonomy strings
3. Fill in questions row-by-row
4. **Leave columns 1, 2, 20, 26 empty** (auto-generated/fixed)
5. Save as CSV (UTF-8 encoding recommended)

### Step 2: Upload via Admin Panel
1. Go to **Admin → Extracted Questions** page
2. Click **"Bulk Upload CSV"** button
3. Select your prepared CSV file
4. Wait for validation to complete

### Step 3: Review Validation Results
The system will show:
- ✅ **Valid rows**: Green, ready to import
- ❌ **Invalid rows**: Red, with specific error messages
- 🔄 **Duplicate rows**: Yellow, matches existing PYQ

### Step 4: Fix Errors (if any)
Common errors:
- **"Question taxonomy is not an approved exam_topics.csv mapping"**
  → Fix: Use exact spelling from `exam_topics.csv`
- **"A PYQ question needs the year"**
  → Fix: Add valid year (2000-2026) in `year` column
- **"Deduplication Gate: This VINA matches PYQ"**
  → Fix: Change `source_type` to `PYQ` or modify question text

### Step 5: Confirm Import
1. Review the validation summary
2. Click **"Confirm Import X Valid Rows"**
3. Wait for database insertion to complete
4. Check the questions grid to verify

## 🚫 Common Mistakes to Avoid

### ❌ Mistake 1: Using Hardcoded/Random Topic Names
```csv
macro_topic,micro_topic
Science,Newton's Laws  ← WRONG (not in catalog)
```

### ✅ Correct: Use Exact Catalog Strings
```csv
macro_topic,micro_topic
Physics,Mechanics & Properties of Matter  ← CORRECT
```

---

### ❌ Mistake 2: Missing Year for PYQ
```csv
source_type,year
PYQ,  ← WRONG (empty year)
```

### ✅ Correct: Always Provide Year for PYQ
```csv
source_type,year
PYQ,2024  ← CORRECT
```

---

### ❌ Mistake 3: Wrong Exam Tag
```csv
exam_tag
TNPSC GROUP 4  ← WRONG (space instead of underscore)
Group4  ← WRONG (missing prefix)
```

### ✅ Correct: Use Exact Format
```csv
exam_tag
TNPSC_GROUP_4  ← CORRECT
```

## 🔒 Database Enforcement

The `question_taxonomy` table has a **database trigger** that prevents ANY question from being saved with an unapproved taxonomy combination. This ensures:

✅ **Zero mismatch** between questions and syllabus  
✅ **Clean mock test generation** (200Q always maps correctly)  
✅ **Accurate analytics** (syllabus mastery tracks exact topics)  
✅ **Reliable Interactive Syllabus** (students see only real topics)

**This validation happens at the database level, so it cannot be bypassed by the admin panel, API, or import scripts.**
