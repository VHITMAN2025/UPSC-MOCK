## THE PROMPT TO GIVE TO AI

```
I need you to generate a CSV file containing TNPSC exam questions following this exact format and structure.

**File Format:**
- UTF-8 encoding (required for Tamil Unicode characters)
- 29 columns total
- Bilingual: All questions must be in both English and Tamil
- Comma-separated values

**Column Headers (EXACTLY as shown):**
```
question_id,content_hash,exam_tag,source_type,year,subject_name,unit_code,unit_name,macro_topic,micro_topic,sub_topic,difficulty_level,question_type,cognitive_skill,ideal_time_seconds,en_question_text,en_option_a,en_option_b,en_option_c,en_option_d,en_option_e,ta_question_text,ta_option_a,ta_option_b,ta_option_c,ta_option_d,ta_option_e,answer_key,en_explanation,ta_explanation
```

### FIELD SPECIFICATIONS

**Empty Fields (leave blank):**
- `question_id` - Auto-generated by system
- `content_hash` - Auto-generated by system
- `sub_topic` - Optional, leave blank unless specifically needed

**Required Values:**

1. **exam_tag** (MUST use exactly one of these):
   - `TNPSC_GROUP_1` - For Group 1 questions
   - `TNPSC_GROUP_2` - For Group 2 questions
   - `TNPSC_GROUP_4` - For Group 4 questions

2. **source_type**:
   - `PYQ` - Previous Year Questions
   - `VINA` - Simulated/Practice Questions

3. **year**: 
   - Use years like `2024`, `2023`, `2026` (for future practice questions)

4. **subject_name**:
   - `General Studies` - For GS topics
   - `Aptitude & Mental Ability` - For aptitude topics

5. **difficulty_level** (⚠️ CRITICAL - MUST DISTRIBUTE PROPERLY):
   - `EASY` - Basic recall questions (20% of questions per unit)
   - `MEDIUM` - Standard application questions (50% of questions per unit)
   - `HARD` - Advanced analysis questions (30% of questions per unit)
   
   **IMPORTANT:** Use ONLY uppercase (EASY, MEDIUM, HARD). 
   **DISTRIBUTION RULE:** For every unit, maintain 20% EASY, 50% MEDIUM, 30% HARD ratio.
   Example: 10 questions = 2 EASY + 5 MEDIUM + 3 HARD

6. **question_type**:
   - `Multiple Choice` - Standard MCQ format

7. **cognitive_skill**:
   - `Recall` - Memory-based questions
   - `Comprehension` - Understanding-based questions
   - `Application` - Application of concepts
   - `Analysis` - Higher-order thinking

8. **ideal_time_seconds**:
   - Use `54` (standard time allocation per question)

9. **answer_key**:
   - `A`, `B`, `C`, or `D` (the correct option)
```
